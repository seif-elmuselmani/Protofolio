## 🧑‍💻 About This Project

A **premium personal portfolio** built with pure HTML, CSS & JavaScript — no frameworks, no dependencies. Designed to make a strong first impression with a modern **Glassmorphism** dark/light theme, smooth animations, and full bilingual support (Arabic 🇪🇬 / English 🇬🇧).

> 🏆 Built by the **#1 Place Winner** of Egypt's DEPI Nationwide Competition — Backend Developer specializing in **.NET & MEAN Stack**.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🌗 **Dark / Light Mode** | Smooth theme switching with CSS variables |
| 🌍 **Bilingual (AR / EN)** | Full RTL + LTR layout support with one-click toggle |
| 💎 **Glassmorphism UI** | Premium frosted-glass cards with backdrop blur |
| ✍️ **Typing Animation** | Dynamic role text cycling with cursor effect |
| 📊 **Animated Skill Bars** | Scroll-triggered progress bars with percentages |
| 🖼️ **Certificate Lightbox** | Click-to-zoom certificate viewer |
| 💬 **Testimonials Carousel** | Auto-sliding reviews with navigation dots |
| 🖨️ **Professional Print** | `Ctrl+P` generates a clean 6-page A4 print layout |
| 📱 **Fully Responsive** | Mobile-first design with hamburger drawer nav |
| ⚡ **Zero Dependencies** | Pure HTML, CSS & JS — no npm, no build step |

## 🏃 Run Locally

No setup needed — it's a static site:

```bash
# Clone the repo
git clone https://github.com/seif-elmuselmani/Protofolio.git

# Open in browser
cd Protofolio
start index.html        # Windows
open index.html         # macOS
```

Or just **double-click `index.html`** — done ✅
